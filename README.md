# Shiny Assistant <img src="shinyassistant.ico" alt="Icon" width="32" height="32">

A tool for automating shiny hunting in Pokemon games. 
# Download

Currently only supports Windows

[Latest Official Release](https://github.com/zachspang/ShinyAssistant/releases/latest)

Read the [wiki](https://github.com/zachspang/ShinyAssistant/wiki) for info on how the use this program. 

Note: If using Rosalina input redirection on Gen 7 games read [gen7-setup](https://github.com/zachspang/ShinyAssistant/wiki/gen7-setup)
as they disable wifi breaking input redirection and need a patch to work properly.

# Features
- Shiny Pokemon detection
- Discord webhook notifications to ping a user when a shiny is detected
- 3 virtual controller types available, XInput for use with most applications, [sys-botbase](https://github.com/olliz0r/sys-botbase) for direct control of a Switch running CFW,
  and Rosalina menu input redirection for direct control of a 3DS running [Luma3DS CFW](https://github.com/LumaTeam/Luma3DS)
- Macro editor to customize for different scenarios
- Supports random encounters and static hunting
- Tracker for number of encounters
